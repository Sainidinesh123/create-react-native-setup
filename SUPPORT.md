## Before opening an issue

Please include:

- `create-react-native-setup` version (`npm view create-react-native-setup version`)
- Node.js version (`node -v`)
- OS
- Exact command
- Relevant terminal output or `create-react-native-setup-report.json`

## What we do not support here

- General React Native / Android Studio / Xcode setup unrelated to this CLI  
- Expo managed workflow (this tool targets **bare** React Native)  
- Production Firebase / APNs account configuration beyond what the generator documents
